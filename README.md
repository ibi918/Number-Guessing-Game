# Number-Guessing-Game
A beginner-friendly Number Guessing Game developed using Python. The computer generates a random number between 1 and 100, and the player tries to guess it with helpful hints. This project demonstrates Python fundamentals, including loops, conditional statements, user input, and the random module.
🎮 Python Number Guessing Game

A beginner-friendly Number Guessing Game built using Python.

📌 About the Project

The computer generates a random number between 1 and 100. The player tries to guess the correct number. After every guess, the program provides hints:

- Too low: Try a higher number.
- Too high: Try a lower number.
- Correct: Congratulations!

🚀 Features

- Random number generation
- Interactive user input
- Higher and lower hints
- Attempt counter
- Simple terminal interface

🛠️ Technologies

- Python 3
- Random module
- VS Code

▶️ How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

python main.py

📚 Concepts Practiced

- Variables
- While loops
- If-else statements
- User input
- Random module
- Break statement
